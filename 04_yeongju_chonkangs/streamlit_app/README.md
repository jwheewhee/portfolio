# 빈집 활용 촌캉스 사업 — Streamlit 웹 데모

2024 영주시 데이터 분석·활용 공모전에서 진행한 프로젝트를, 이후 Streamlit을 학습해
실제 웹사이트 형태로 재구현한 데모입니다. 원본 크롤링 데이터(CSV)는 보관하고 있지 않아,
실제로 도출했던 최종 결과와 분석 로직(하버사인 거리 계산, 관광지×맛집×빈집등급 스코어링)을
그대로 재현했습니다.

🔗 **배포 링크**: [여기에 배포 후 URL 추가 예정]

## 주요 기능
- **최종 결과**: 종합 점수 기준 상위 5개 지역 순위표 및 시각화
- **지도로 보기**: Folium 기반 인터랙티브 지도로 최종 후보 지역 표시
- **스코어링 계산기**: 실제 분석에 사용한 `관광지 점수 × 맛집 점수 × 빈집 등급 점수` 로직을
  슬라이더로 직접 조작해볼 수 있는 인터랙티브 데모

## 로컬 실행 방법
```bash
pip install -r requirements.txt
streamlit run app.py
```

## 사용 기술
`Python` `Streamlit` `Folium` `Pandas` `NumPy`
