## 데이터 출처
- 출처: 영주시 데이터 분석·활용 공모전 측 제공 자료 (관광지/맛집/빈집 등급/행정복지센터 목록)
- 취득 방법: 공모전 참가팀에 한해 배포된 원본 csv
- 취득 시점: 2024

## 주요 컬럼 설명
| 컬럼명 | 설명 | 타입 |
|---|---|---|
| 읍면동명 | 19개 읍면동 이름 | str |
| 행정복지센터_위경도 | 빈집 대표 좌표로 사용한 행정복지센터 위치 | float, float |
| 빈집등급 | 1~4등급 (분석 대상은 1·2등급만) | int |
| 관광지명 / 관광지_인기순위 | 읍면동별 관광지 목록 및 순위 | str / int |
| 맛집명 / 맛집_방문객수 | 읍면동별 맛집 목록 및 방문객 수 | str / int |
| 종합점수 | 관광지 점수 × 맛집 점수 × 빈집등급 점수 | float |

## 배치 경로
공모전 측에서 제공한 원본 데이터는 배포 제한이 있어 저장소에 포함하지 않았습니다.
컬럼 구조가 같은 샘플 데이터가 필요하면 위 컬럼명 그대로 5행짜리 sample.csv를 만들어 사용하면 됩니다.
