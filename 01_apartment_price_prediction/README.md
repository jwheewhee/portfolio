# 🏠 아파트 실거래가 예측 (데이콘 해커톤 2위)

수원대학교 데이터 청년 캠퍼스 프로그램 중 진행한 예비 프로젝트로, 데이콘에서 주최한
[아파트 실거래가 예측 해커톤](https://dacon.io/competitions/open/236130)에 5인 팀으로 참가해 16팀 중 2위를 기록했습니다.

## 배경 / 목표 / 성공 기준
- **배경**: 면적·층·건축연도가 비슷해도 실거래가는 단지마다 편차가 큽니다. 그러다 보니 매수자 입장에서는 제시된 가격이 적정한지 스스로 판단하기 어렵습니다.
- **목표**: 전용면적·층수·건축연도·거래연월 같은 기본 정보만으로 적정가를 예측하는 모델을 만드는 것이었습니다.
- **성공 기준**: 대회 평가지표인 MAE를 기준으로 삼아, 처음 접근했을 때보다 오차를 확실히 낮추는 걸 목표로 잡았습니다.

처음엔 LGBM 단일 모델로 리더보드 하위권에 머물렀는데, 성격이 다른 8개 회귀 모델을 묶은 보팅 앙상블을 제안·구현한 뒤 오차가 크게 줄면서 순위가 올라갔습니다.

## 🔍 접근 방식

### 1) 전처리
- 예측에 사용할 변수만 선택: `전용면적`, `층수`, `건축연도`, `거래연월`
- 거래연월(YYYYMM)을 `거래연도` / `거래월`로 분리해 계절성·연도 트렌드를 학습할 수 있게 처리
- 시군구+아파트명 조합, 면적 구간화 같은 파생변수도 추가해봤지만 오히려 MAE가 나빠져서 단순 변수로 되돌림

### 2) 모델링 - 보팅 앙상블
서로 다른 성격의 회귀 모델 8개를 각각 하이퍼파라미터 튜닝한 뒤, `VotingRegressor`로 결합해 예측값을 평균했습니다.

| 모델 | 역할 |
|---|---|
| LightGBM | 빠르고 정확도 높음 |
| Random Forest | 과적합 덜하고 안정적 |
| XGBoost | 부스팅 기반, 정교한 예측 |
| CatBoost | MAE를 손실함수로 직접 최적화 |
| Ridge | 선형 관계 포착, 정규화로 과적합 방지 |
| Gradient Boosting | 순차적으로 오차 보정 |
| SVR | 비선형 관계 포착 |
| AdaBoost | 약한 학습기를 모아 보완 |

서로 다른 모델의 예측을 합치면 각 모델의 편향이 상쇄돼서 더 안정적으로 예측할 수 있다는 게 핵심이었습니다. 앙상블 검증과 하이퍼파라미터 조정은 팀원들과 계속 같이 실험하면서 진행했습니다.

## 🛠 사용 기술
`Python` `Pandas` `Scikit-learn` `LightGBM` `XGBoost` `CatBoost` `Voting Ensemble`

## 👤 본인 역할 (5인 팀)
- 파생변수 추가가 오히려 MAE를 악화시킨다는 걸 직접 검증하고, 단순 변수로 되돌리는 판단 주도
- 예측 오차 개선이 막힌 상황에서 보팅 앙상블 기법을 제안하고 직접 구현
- 8개 모델 하이퍼파라미터 튜닝 - 앙상블 결과 공유와 튜닝은 팀원들과 함께 반복 실험
- 팀 코드 공유, 진행 상황 관리, 발표 자료 정리

## 💡 배운 점
막혔을 땐 기존 방식을 다듬기보다 접근 자체를 바꾸는 게 더 효과적일 수 있다는 걸 체감했습니다. 성과가 안 나와서 팀 사기가 떨어졌을 때, MAE 개선 같은 확실한 숫자가 팀을 다시 움직이게 한다는 것도 배웠습니다.

## 🔎 한계 / 아쉬운 점
- 파생변수를 추가했을 때 왜 MAE가 나빠졌는지, 개별 변수 기여도까지는 확인하지 못했습니다. 결국 변수를 되돌리는 선에서 마무리했습니다.
- 교차검증 설계나 random seed 고정, 데이터 누수 점검을 꼼꼼히 하지 않아서, validation 성능이 test에서도 똑같이 재현될지 확신은 없었습니다.
- 고가 구간은 데이터가 적어서 오차가 컸을 수 있는데, 가격대별로 오차를 나눠서 확인하지는 않았습니다.
